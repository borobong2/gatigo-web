# #15 이동시간 정확도 원인 조사와 보정 전략 선택

## 관찰

`신대방삼거리역 → 당산역`은 현재 정적 그래프에서 13분으로 계산되지만,
실제 대중교통 길찾기 기준값은 약 23분이다. 추천 순위가 사람별 이동시간에
의존하므로 이 오차를 모른 채 Gate 0 행동 데이터를 해석하면 안 된다.

## 목표

정적 예상시간과 실제 여정시간의 차이를 구성 요소별로 측정하고, 표시 의미와
추천 순위를 신뢰할 수 있게 만드는 가장 작은 보정 전략을 선택한다.

## 조사 범위

- 알려진 `13분 vs 23분` 사례의 최단 경로와 간선 시간을 재현한다.
- 차내시간, 최초 대기, 환승 도보·대기 등 누락된 시간을 분리한다.
- 직통·1회 환승·다회 환승을 포함한 대표 경로 10개 이상을 비교한다.
- 정적 보정과 외부 대중교통 경로 소스를 정확도, 반복비용, 자격증명, 지연,
  라이선스, 개인정보 측면에서 비교한다.
- 선택할 전략, 허용 오차, 사용자에게 보여줄 시간 라벨을 제안한다.

## 산출물

- 경로별 정적값, 기준값, 절대·상대오차, 환승 수, 추적 경로 표
- 측정 근거로 순위를 매긴 원인 목록
- 권장 전략과 회귀 검증 기준
- 승인된 전략을 구현할 후속 이슈 초안

## 제외 범위

- 운영 계산이나 문구 변경
- 유료 API 구독 또는 새 자격증명 발급
- 모든 경로에 임의로 10분을 더하는 보정
- 모임방, 공유, 지도, 맛집, 모바일 기능

## 중단 조건

권장 전략에 비용, 자격증명 또는 데이터 정책 결정이 필요하면 구현하지 않고
`loop:needs-human`으로 올린다.
