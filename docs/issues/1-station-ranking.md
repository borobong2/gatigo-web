# #1 출발역 두 개로 만날 곳 추천받기

## Goal

두 사람이 출발역을 입력하면, 실제 대중교통 소요시간을 바탕으로 만나기 좋은
후보 역 3개를 화면에서 바로 비교한다.

## Scope

- 출발역 두 개를 검색·선택하는 화면을 만든다.
- `POST /api/meeting-suggestions` Route Handler를 만든다.
- 정적 지하철 그래프로 후보 역을 빠르게 좁힌다.
- 서버에서 카카오 대중교통 경로 API를 호출해 각 후보의 실제 소요시간과
  길찾기 URL을 가져온다.
- `최대 이동시간`이 짧은 후보를 우선하고, 동률이면 `총 이동시간`이 짧은 순으로
  결과 카드 3개를 표시한다.
- 로딩, API 오류, 잘못된 역 선택 상태를 화면에서 처리한다.

## Non-goals

- 모임방 저장, 공유 링크, 여러 참여자 실시간 응답
- 맛집, 예약, 지도 SDK 렌더링
- 버스·실시간 도착정보 최적화

## Done when

- 강남역과 홍대입구역처럼 두 출발역을 선택하면 후보 역 3개와 사람별 실제
  대중교통 소요시간이 화면에 보인다.
- 결과 카드의 길찾기 버튼은 카카오맵 대중교통 경로를 연다.
- 카카오 REST API 키는 `KAKAO_REST_API_KEY` 서버 환경변수로만 읽고 브라우저에
  노출하지 않는다.
- API 호출은 mock 기반 테스트로, 후보 순위는 단위 테스트로 검증한다.
- 유효한 API 키가 있는 개발 환경에서 한 번 실제 응답을 확인한다.
