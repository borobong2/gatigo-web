# #1 출발역 두 개로 만날 곳 추천받기

## Goal

여러 사람이 출발역을 입력하면, 정적 수도권 전철망에서 모두에게 덜 먼 만남역을
추천한다.

## Scope

- 수도권 전철을 정점(역)·간선(같은 노선의 인접역)으로 표현한다.
- 인접역 간선에는 정적 기본 운행시간(분)을 두고, 환승은 초기 3분 패널티로
  시작한다.
- 후보 역마다 각 출발역까지 Dijkstra 정적 예상시간을 계산한다.
- `worst`(가장 오래 걸리는 사람의 예상시간)를 우선 최소화하고, 동률이면
  `total`(예상시간 합)이
  작은 순으로 후보 역 3개를 표시한다.
- 추천 이유와 사람별 정적 예상시간을 결과 카드에서 읽을 수 있게 한다.
- 잘못된 역 선택과 연결되지 않은 역 상태를 화면에서 처리한다.

## Execution checklist

- [x] 수도권 전철 전체의 노선·인접역·환승 원본을 라이선스와 범위까지 검증하고,
      불명확하면 `docs/loop/STATE.md`에 blocker로 남긴다.
- [ ] 검증된 원본을 저장소의 정적 네트워크 데이터와 출처·범위 문서로 반영한다.
- [ ] 정적 기본 운행시간과 환승 3분 패널티의 Dijkstra, `worst` → `total` 후보
      정렬을 테스트와 함께 구현한다.
- [ ] 카카오 클라이언트와 런타임 외부 호출을 제거하고, 결과 화면에 정적 예상시간과
      추천 이유를 표시한다.
- [ ] 전체 검사와 브라우저 확인을 기록하고 `STATE.md`를 완료 상태로 갱신한다.

> Source selected: 국가철도공단 `국가철도공단_도시광역철도_운행정보_20260228`
> (전체 도시광역철도 운행기관, 이용허락범위 제한 없음)을 정규화한다. 원본의
> 정거장 순서와 정적 도착·출발 시각으로 인접역 기본 운행시간을 만들고, 원본을
> 런타임에 조회하지 않는다. 역·환승 메타데이터는 같은 기관의
> `국가철도공단_도시광역철도_역사정보_20241231`을 보조 원본으로 사용한다.

## Non-goals

- 실시간 시간표·실제 대중교통 소요시간·외부 길찾기 API
- 카카오/네이버 지도 SDK와 API 키
- 맛집, 예약, 모임방 저장·공유 링크
- 버스·실시간 도착정보 최적화

## Done when

- 강남역과 홍대입구역처럼 출발역들을 선택하면 후보 역 3개와 사람별 정적 예상시간이
  화면에 보인다.
- 외부 API 호출과 API 키 없이 결과가 계산된다.
- `worst` 우선, 동률 시 `total` 우선의 minimax 정렬 규칙을 단위 테스트로 검증한다.
- 환승 3분 패널티가 경로 계산에 반영되는 것을 테스트로 검증한다.
